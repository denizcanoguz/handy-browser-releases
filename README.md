# Handy Browser

Sesli ve görüntülü sohbeti olan masaüstü tarayıcı. Bu sayfa sadece indirmek içindir.

## İndir

[Releases](../../releases/latest) sayfasından en son **Handy Browser Setup x.y.z.exe** dosyasını indir.
Sadece Windows (64 bit).

## Kurulum

1. İndirdiğin dosyayı çalıştır. Kurulum soru sormadan biter; masaüstüne kısayol ekler.
2. Windows **"Windows bilgisayarınızı korudu"** derse: **Ek bilgi → Yine de çalıştır**.
   Dosya imzasız (imza ücretli bir sertifika gerektiriyor); bu uyarı bundan.

## İlk açılış

1. Giriş ekranında **Bağlanılan adres → Değiştir**'e bas.
2. Sana verilen `https://....trycloudflare.com` adresini yapıştır, **Kaydet**.
3. **Kayıt ol** ile hesap aç.
4. Şifreni unutursan kurtarabilmek için **Ayarlar > Hesap**'tan e-posta ekle.
5. Sana verilen davet koduyla sunucuya katıl.

Adres zaman zaman değişebilir. Değişirse yeni adresi aynı yere yazman yeterli; hesabın ve
sunucuların silinmez, sadece yeniden giriş yaparsın.

## Kaldırma

Ayarlar > Uygulamalar (ya da Denetim Masası > Programlar) içinden **Handy Browser**.
